# 功能描述

网盘主要提供文件托管，文件上传，文件下载服务。主要面临的挑战是海量数据的高并发读写。

包括【数据存储】【频繁读写】【网络宽带】三个方面的瓶颈。

网盘的核心功能是文件上传/下载服务，以及文件断点续传。在扩展方面，可以实现文件的共享，文件的播放。对于上传下载，可以基于用户身份进行流量控制。

## 功能需求

1. 支持用户注册登录网盘。
2. 上传文件，下载文件。
3. 分享文件
4. 查看文件目录
5. 查看文件列表
6. 查看任务列表
7. 新增/删除文件夹
8. 播放已上传视频

# 数据库设计

![数据库E-R图1.drawio](https://s2.loli.net/2025/09/02/Ql3HAha6VEYU4si.png)

**服务器**

网盘需要数据库持续存储的数据包括

1. 用户信息，用于判断用户的登录注册。

2. 文件信息
3. 用户与文件的关系

**客户端**

使用userid作为数据库的名字，给每个用户创建一个数据库。用户数据库用来记录所有的上传下载信息。

总共需要两张表，时间戳作为主键，分别记录

timestamp->上传任务

timestamp->下载任务
